# 🎮 Delphi Canvas Game

**A small game drawn on a Delphi canvas**

## ✨ Features

- Graphics drawn directly on a VCL canvas
- Lightweight Windows desktop app
- Good example of Delphi canvas basics

## 🚀 Getting Started

1. Open `erensolmaz.dproj` in **Embarcadero Delphi** (RAD Studio).
2. Build & run (`F9`), or launch the prebuilt `Win32/Debug/erensolmaz.exe`.
